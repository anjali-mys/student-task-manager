# Student Task & Deadline Manager

## About the Project
Student Task & Deadline Manager is a web application designed to help students organise their academic work in one place. It helps students manage assignments, track deadlines, monitor task completion, and view their weekly timetable.

## Features
- **Dashboard:** View an overview of tasks and progress.
- **Task Management:** Add and manage academic tasks.
- **Deadline Tracking:** Keep track of upcoming deadlines.
- **Progress Tracking:** Mark tasks as completed and monitor progress.
- **Timetable:** View a weekly class timetable.

## Technologies Used
- Next.js
- React
- JavaScript
- Tailwind CSS

## Getting Started

First, install the project dependencies:

```bash
npm install
```

Then start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## Project Purpose
The goal of this project is to make academic planning easier by helping students stay organised and manage their time effectively.
